# アトリエひなたぼっこ 公式サイト

群馬県藤岡市の小さなアトリエ「アトリエひなたぼっこ」のWebサイトです。

- 公開URL：https://atelier-hinatabokko.github.io

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| index.html | サイト本体(トップページ) |
| favicon.png | ブラウザのタブに表示されるアイコン |
| apple-touch-icon.png | iPhoneで「ホーム画面に追加」したときのアイコン |
| ticket/ | 縁日用チケット管理アプリ(イベント終了のため現在は未使用) |
